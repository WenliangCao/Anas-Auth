## 描述（≤ 4000）

Anas Auth 是一款原生、开源的两步验证 App，支持 iPhone 和 iPad。（Anas 在拉丁语里是"鸭子"的意思。）

它完全使用 Apple 自家的框架编写，打开即用，滑动流畅，外观与系统保持一致。

验证码只属于你
• 无需注册账号，我们也没有任何服务器。验证码保存在你的设备上，并通过你私人的 iCloud 数据库同步。
• 没有统计分析，没有广告，不做任何追踪。
• 可选 Face ID、触控 ID 或设备密码解锁；在多任务界面中内容会自动模糊。
• 随时导出加密备份。

添加方便，迁移轻松
• 扫描二维码、从相册选取二维码图片，或手动输入密钥。
• 支持从 Ente Auth、2FAS、Aegis、andOTP、Bitwarden、Google Authenticator、Proton Authenticator、Raivo OTP、LastPass Authenticator、OTP Auth 导入，也支持 otpauth:// 纯文本列表。

为日常使用而设计
• 轻点卡片即可复制验证码；复制的验证码只留在本机，60 秒后自动从剪贴板清除。
• 当前验证码快到期时，可以提前看到下一个。
• 数千个服务的品牌图标，自动匹配。
• 置顶常用账号，用标签分类，支持搜索，可按名称、账号、最常用或最近使用排序。
• 默认与紧凑两种布局，支持浅色和深色模式。
• 支持 TOTP、HOTP 与 Steam 验证码。

开源
Anas Auth 是自由软件，以 GNU AGPL-3.0 许可发布，完整源代码见：
https://github.com/WenliangCao/Anas-Auth

Anas Auth 是受 Ente Auth 启发的独立项目，与 Ente 没有隶属关系。
